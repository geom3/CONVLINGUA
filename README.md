## 📖 About The Project

This is the official landing page and digital storefront for **CONVLINGUA**, an independent, 22-person AI data and localization agency. The agency serves as a secure, managed backend for Tech Recruiters, Vendor Managers, and AI Founders, providing high-throughput capacity for:

* **Generative AI Operations:** SFT, RLHF, Reward Modeling, and side-by-side (SxS) prompt evaluation.
* **Multilingual LQA:** High-volume localization and cultural adaptation.
* **Voice Data Collection:** Native, on-the-ground Arabic audio and speech dataset collection.
* **Dialect Focus:** Native Arabic (MSA, Egyptian, Gulf, and Maghreb) and Advanced English.


## ⚡ Features

* **Modern, Responsive UI:** Fully optimized for desktop, tablet, and mobile viewing.
* **Performance Focused:** Built with semantic HTML and modern, lightweight CSS for lightning-fast load times.
* **B2B Conversion Optimized:** Strategically structured to guide Vendor Managers and Enterprise Partners toward booking discovery calls and requesting capability decks.
* **RTL/LTR Ready:** Designed with deep structural consideration for Arabic/English visual hierarchy.

## 🛠️ Tech Stack

* **Markup:** HTML5
* **Styling:** CSS3 (Modern CSS variables, Flexbox, CSS Grid)
* **Scripting:** Vanilla JavaScript (ES6+)
* **Design/Prototyping:** Figma
